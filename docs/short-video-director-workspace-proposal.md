# 一分钟短视频导演台：修改提案与交接

## 决策

将现有脚本、首帧、逐镜生成、Ref2VA 局部修改和合片流程收进同一个导演台。目标是让 15–60 秒短视频能在一个脚本中完成镜头确认、选片和轻剪辑；使用视频与字幕共用的整片时间轴，沿用脚本镜头顺序和编辑数据。原有视频修改能力继续负责画面内容变更，裁切只负责成片的起止时间，两者用途不同。

代码位于 `feat/short-video-director-workspace` 分支。主要提交：

- `2c3a547`：导演台与已有镜头流程整合。
- `c641f9a`：分镜预演、裁切、字幕、合片及 Agent 接口，并清理重复逻辑。
- `3821f62`：Agent REST 处理器的鉴权、版本锁与数据库集成测试。

## 已实现

1. 导演台按脚本镜头展示生成和 Ref2VA 修改版本，可预览并锁定合片采用的 take；镜头顺序与末帧接力沿用脚本流程。
2. 所有镜头选定首帧后，可用 FFmpeg 生成无声的静态分镜预演，不调用 H3。预演按脚本版本校验访问，删除脚本时清理对象。
3. 每镜可设置起止裁切和可修改的字幕时间码；从脚本台词可生成字幕草稿。字幕生成不做 ASR，也不保证和实际语音自动对齐。
4. 合片使用已选 take，应用裁切，并可选择烧录字幕。裁切和字幕进入合片任务指纹，修改后不会误用旧成片；原视频文件不变。
5. 脚本镜头的版本锁更新共用一处逻辑。普通脚本 PATCH 保留未显式改变的选片、裁切和字幕，避免远程 Agent 覆盖导演台状态。镜头编辑字段存于现有 JSON 列，无数据库迁移。

主要代码：`apps/media-hub/src/components/director-stage.tsx`、`apps/media-hub/src/routes/scripts.tsx`、`packages/api/src/router/media-hub/video-script.ts`、`video-script-assembly.ts`、`video-script-edit-plan.ts` 和 `video-script-render.ts`。

## 远程 Agent 接口

Bearer Token 鉴权；脚本更新使用最新 `GET /api/v1/scripts/{scriptId}` 返回的 `version`。完整请求结构见 `GET /api/openapi`。

| 操作       | 接口                                                               | 要点                                                                   |
| ---------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 选定 take  | `PATCH /api/v1/scripts/{scriptId}/shots/{shotId}/take`             | `job_id`、`version`；只能选本人该镜已成功的任务                        |
| 裁切与字幕 | `PATCH /api/v1/scripts/{scriptId}/shots/{shotId}/edit-plan`        | `version`、可选的 `trim_start_seconds`、`trim_end_seconds`、`captions` |
| 字幕草稿   | `POST /api/v1/scripts/{scriptId}/shots/{shotId}/captions/generate` | `version`；用脚本台词覆盖该镜字幕草稿                                  |
| 分镜预演   | `POST /api/v1/scripts/{scriptId}/animatic`                         | 返回脚本版本及带鉴权的视频地址                                         |
| 合片       | `POST /api/v1/scripts/{scriptId}/assemble`                         | 可选 `{ "burn_captions": true }`；返回成片任务                         |

预演视频由 `GET /api/v1/scripts/{scriptId}/animatic/{version}/video` 读取；成片视频沿用 `GET /api/v1/generations/{jobId}/video`。

## 本次接手补齐的缺口（2026-10-03）

- 预演对象改为按账号、脚本和版本分别存储，旧预演不会从新版本 URL 返回。删除会清理所有版本及旧格式对象，存储失败后可重试清理。
- 合片以脚本版本和任务开始时间保护写入；取消、编辑、删除或新重试不会被旧任务覆盖。每次尝试使用独立对象路径，事务保证成功任务与发布草稿一起落库。失败可重试，成功结果复用，超过 10 分钟的遗留运行任务可重新认领。
- 前后端使用同一选片规则；优先展示当前组合的成片，字幕标签来自输出记录。尺寸进入任务指纹，未保存草稿不会继续标为当前成片。
- 裁切和字幕由父级草稿统一管理，切镜保留输入，合片前自动保存。动作互斥并禁用编辑，避免重复提交和保存时覆盖新输入；镜头页签改为 Radix Tabs，脚本删除改为 AlertDialog。
- 页面工作流移至 hook，编辑控件、草稿模型、脚本文档更新、预演服务与渲染限流分别独立；存储包拥有自己的对象清理测试。
- 每个工作进程串行处理 FFmpeg，最多等待 8 个任务，5 分钟处理期限，子进程与存储读取接收取消信号。逐镜读取素材，临时文件在失败和取消时清理。
- 拼接统一 H.264/AAC、24 fps 和脚本尺寸，修复不同编码参数直接拼接产生帧率异常的问题。验证实际字幕像素、镜头顺序、音轨、尺寸和时长。
- 清理全量 lint 错误、测试服务器及数据库连接、未使用的报销单 CSS 和外部字体请求；CI 增加 lint 和中文字体，运行镜像增加中文字体，集成测试取消结果缓存。

## 运行边界与上线验收

### 整片时间轴（2026-10-07）

导演台以整片为编辑对象：移除逐镜页签与全部镜头表单列表，所有片段按脚本顺序显示在同一条视频轨上，字幕共用整片时间尺。点击片段才显示对应裁切、字幕与版本配置；首帧、画面、摄影、台词和声音设置收在选中片段的折叠配置区。添加片段也从时间轴入口操作。

拖动片段可重排，松开指针后提交；键盘用户可用“前移片段 / 后移片段”。拖动边界调整素材入点和出点，至少保留 1 秒；后续片段和所属字幕自动更新整片偏移。选中片段在排序后保持选中。字幕按导出规则裁去范围外部分，丢弃不足 0.1 秒的部分；重叠字幕另起一行，拖拽时固定行归属，取消指针操作恢复原范围。

字幕轨与属性输入使用整片秒数，保存时转换为所属素材秒数，沿用现有 JSON 字段与合片服务。字幕移动和边界调整限定在所属片段内（最短 0.1 秒），跟随片段排序。裁切入点和出点输入仍使用素材秒数，并在配置区说明。

当前时间轴只显示一个连续播放器，依次播放每个已选版本的裁切范围，整片时间尺可跨镜头定位，末尾暂停并可从头重播。尚未生成或选片的片段保留在轨道上，预览显示待完成提示。已导出成片、成片修改版与分镜预演从预览版本菜单查看，成片局部修改仍使用实际成片时长。修改时间轴会回到当前剪辑预览，合片前仍由原工作流保存完整草稿。

主要代码为 `director-stage.tsx`、`composition-preview-player.tsx`、`shot-timeline.tsx`、`shot-edit-controls.tsx`、`director-workspace.tsx` 与 `lib/shot-timeline.ts`。没有新增运行依赖或数据库迁移。当前导演台合片使用硬切，时间轴按相同规则计算偏移；已有转场接口继续保留。

验收覆盖整片偏移与后端字幕计划一致性、跨镜头定位和连续播放、裁切后后续位置更新、片段重排、字幕移动与取消、键盘选择、草稿保留以及导出参数。浏览器使用隔离本地视频测试页，不连接生产数据库；确认单一播放器、桌面与 390 像素移动布局，以及连续切换片段。本次未部署。

本次应用非数据库测试 19 文件、78 项通过，后端字幕计划与真实 FFmpeg 渲染测试 2 文件、4 项通过；应用类型检查、变更组件 lint、生产构建和差异空白检查通过。数据库集成测试因本机 Docker 不可用未能运行。桌面和移动截图保存在 `artifacts/composition-timeline-20261007/`。

### 时间轴局部画面修改（2026-10-07）

选中已完成的片段后，时间轴下方直接显示“修改选中片段”，不必先展开版本列表。打开后在原整片时间尺增加修改范围轨道，可拖动范围及两端边界，或输入整片秒数；播放器仍使用同一整片预览。范围限制在选中片段保留的素材区间内，提交时要求长度为 2–15 秒，并转换为实际源视频时间。修改描述、参考图、AI 优化和定时执行沿用已有编辑能力，`generation.createEdit` 请求保留 `preserveSourceAudio: true`，不新增接口或数据库字段。

提交前锁定当前素材版本；锁定失败会保留修改草稿并阻止创建任务。上传和创建任务期间，片段切换、范围修改、版本选择及合片暂时禁用，避免修改源和提交范围不一致。提交完成后展开片段版本，排队中的修改版不会替换原预览，完成后用户可选用修改版并重新合片。

新增检查覆盖整片时间换算、修改范围更新、未完成素材禁用、提交期间控件锁定、前置锁定错误与忙碌状态传播。当前应用非数据库测试 20 文件、86 项通过，类型检查、变更组件及 hooks lint、生产构建通过。浏览器以真实组件和本地视频、模拟接口验证桌面及 390 像素手机界面、范围拖动、提交参数和排队版本展示：整片 4.5–7.5 秒对应第二个素材 1.5–4.5 秒，原裁切与预览保留。截图位于 `artifacts/clip-edit-20261007/`。本机 Docker 不可用，数据库集成测试未通过环境初始化；未提交真实 GPU 任务，未部署线上。

合入最新 `main` 时保留了独立镜头合片、白/黑转场和原位重建接口。转场支持裁切与字幕组合，字幕时间码扣除镜头间重叠；输出统一为 24 fps，任务时长向上取整以适配现有整数列。重建复用原任务与草稿，失败保留旧视频；草稿进入审核或已有发布目标时拒绝替换，并在提交时再次检查。

渲染仍在应用请求工作进程执行，内存队列不跨实例共享；重启后的遗留任务通过重试回收。未引入持久化队列服务，也没有数据库迁移。

上线验收仍需在真实测试环境检查 H3/Ref2VA GPU 生成、中文语音与字幕对齐，以及正式对象存储的播放和下载。字幕来自脚本台词，需要人工校对。发布由合入 `main` 后的 Docker 工作流执行；本次测试没有执行真实 GPU 生成或平台发布。
