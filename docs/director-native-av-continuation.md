# 导演台原生音视频衔接修复

此次问题来自接入和制作决策：导演台逐镜独立生成，连续性设定仅进入文字提示词，没有传入上一镜的音视频；普通长视频模式也只传末帧。S1 标签不是声纹参考。PPT 插图被人为当成风格约束，后续镜头被写成微缩机关；试听又替换成了本机 Tingting。前两种生成入口实际使用同一 H3 模型、20 步和 1024×576，未发现导演台自动降低步数的证据。

## 已实现的产品修改

- 导演台与脚本 Agent API 默认使用 `native_av`，仍可明确选择独立镜头。
- 导演台标明支持原生衔接的工作流，按实际选中工作流检查能力；检查未完成或工作流不支持时，所有生成入口在提交前阻止任务。
- 生成任务保存上一镜 ID；后镜等待上一镜通过验收，再提取同步 22 帧末尾视频及音轨。
- 上下文以脚本规定的结束点为准，避免取到合成时会裁掉的多余尾帧，造成动作衔接跳跃。
- GPU Provider 将两路内容连接到官方 `MiniMaxH3AddGuide`，通过视频和音频 VAE 共同引导 FL2VA。若下一镜另选了首帧，该首帧锚定在上下文之后。
- 默认每镜 15 秒，30/45/60 秒分别规划为 2/3/4 镜；原生后续镜头也支持 15 秒。后台为 22 帧上下文额外申请帧数，15 秒续镜按 17k+5 对齐后申请 396 帧，官方 Provider 配置上限同步改为 396，避免被旧的 362 帧上限截短。台词时间自动偏移，生成后从画面和原声音轨一起移除重复上下文。
- 旁白的音色描述和画外音属性贯穿编辑器、Agent API、持久化与 H3 提示词，不用本机或外部 TTS。
- 分镜规划要求具体动作与环境反应，PPT 作为事实来源；首帧不再被强制改成写实照片。
- 默认剪切也按脚本时长裁尾，避免 H3 帧数对齐误差逐镜累积。

无需数据库迁移：使用现有源任务 ID 和镜头 JSON 字段。

## 验证与发布状态

本地相关验证：API 28 项、界面/API 映射 13 项、GPU Provider 15 项测试通过；含真实 FFmpeg 音轨保留、上下文去重、脚本结束点取样、默认裁尾及原生节点能力检测回归。API、前端类型检查及所改生产 TypeScript 文件 lint 通过。系统 FFmpeg 缺少 x265 动态库，媒体测试使用临时目录中的独立 FFmpeg，没有修改系统安装。首次误触全套测试还遇到沙箱端口限制；不能将该次全套测试描述为全部通过。

2026-10-04 已完成现场更新：导演台/API 生产构建部署为 `pumpkii-media-hub:native-av-20261004`；5090 的 Provider 合并原生衔接改动，保留现场已有 GPU broker 及显存释放屏障。两处服务均已重新启动，Agent API 的官方 20 步工作流报告 `supportsNativeAVContinuation: true`。原生相邻两镜的声音与动作仍待生成后的真实试听验收。

现场 ComfyUI 为 `7d11ec31`，原先没有 `MiniMaxH3AddGuide`，模型布局也仅接受首末静态帧。已通过 `backport_native_av_guide.py` 补入官方引导节点、音视频条件布局与音轨传递，保留既有注意力、量化及其他现场改动。CPU 实测验证同步视频/音频行、22 帧之后首帧锚定、H3 前向输出形状与有限数值；重启后节点注册和 Provider 健康检测通过。不支持时仍预检失败，不回退到静态首帧或 TTS。

5090 回滚快照在 `/home/a/.local/share/media-hub-native-av-20261004/`，包含 `provider-backup.py` 和 `comfy-backup/`；服务器保留原 Docker 镜像及服务历史。目前导演台使用本次本地构建镜像，后续常规部署需包含本轮提交的改动。30 秒样片脚本为 `d5157a01-3268-4c18-9324-2c0be46c5b39`，三镜各 10 秒，已通过原生模式提交。

原生音视频条件比文字说话人标签多了实际声学上下文，但仍不是绝对声纹锁定。末尾静音、多人说话会削弱声音条件，故规划器要求同一旁白在片尾仍有可听语句。ASR 验证台词，不验证声纹；上线后的验收必须试听两镜，之后再通过导演台生成约一分钟的横屏动画成片。当前 Tingting 试听版和微缩机关版不作为交付成片。

15 秒默认调整的验证边界：官方节点允许最多 3600 帧，但节点说明将约 124–362 帧列为训练范围，更长时间未测试。396 帧的帧数预算、规划和提交限制已作代码回归；不将已有的 10 秒续镜实测当作 15 秒续镜的 GPU 质量验证。现有样片和已保存镜头不自动改时长或重新生成。
